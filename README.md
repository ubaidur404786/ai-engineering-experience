# The AI Engineering Experience

An interactive, animated book that teaches AI Engineering through stories, visual simulations and real code.

```powershell
npm install
npm run dev
```

Open http://localhost:5173.

- `docs/ARCHITECTURE.md`: stack choices, structure, rules
- `docs/ACCURACY_LOG.md`: where every number on every page comes from
- `src/data/curriculum.ts`: the full 15-part roadmap (unwritten chapters show as "planned" in Contents)
- `src/chapters/tokenization/`: the reference chapter. New chapters follow its pattern.
